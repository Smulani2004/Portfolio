## 👋 About

Welcome to my personal portfolio!

This repository contains the source code for my portfolio website—a place to explore my projects, discover my technical skills, and learn more about my journey.

The interface combines frosted glass panels, gradient accents, and subtle animations to present my work in a clean, engaging way.

## ✨ Highlights

- **Glassmorphism UI** — Translucent cards, soft shadows, and gradient accents.
- **Responsive Layout** — Designed for desktop, tablet, and mobile screens.
- **Project Showcase** — Project descriptions with source code and live demo links.
